How it’s converted

each step explains what it does
01Read Presetspending
A Krita .bundle is a ZIP of presets, tips and patterns. Each .kpp preset is a PNG whose preset text chunk (often zlib-compressed) holds the settings as XML. Filter, clone and other engines that edit pixels instead of painting are skipped.
02Load Tipspending
Generated tips are drawn from their settings. Image tips are read from PNG, SVG and GIMP .gbr / .gih files. CSP draws with dark ink, so each tip is stored dark on white.
03Map Settingspending
Krita's sensor curves are reduced to pressure and speed amounts, rotation (follow stroke or random), roundness, scatter and texture strength. These go through the same mapping as the Procreate → CSP converter.
04Write .sutpending
A CSP .sut is a SQLite 3 database with three tables. Node holds the name, Variant holds the settings as typed columns, and MaterialFile holds the tip as a tar archive containing thumbnail/thumbnail.png. It's built with sql.js (SQLite compiled to WebAssembly). Several presets are downloaded together as a .zip.
