01ZIP Extractionpending
A .brush file is a renamed ZIP archive. Inside: Brush.archive (NSKeyedArchive binary plist with all settings), Shape.png (brush tip stamp, white = opaque), Grain.png (texture overlay), and optional metadata. We use JSZip to decompress entirely in the browser.
02Binary Plist Decodepending
Brush.archive starts with magic bplist00. We read the 32-byte trailer to locate the offset table, then decode each object by its type nibble: 0x0=singleton, 0x1=int, 0x2=float (IEEE 754 BE), 0x4=data, 0x5=ASCII, 0x6=UTF-16BE, 0x8=UID (N+1 bytes), 0xA=array, 0xD=dict.
03NSKeyedArchive → SilicaBrushpending
The plist is an NSKeyedArchive. $top.root points via UID into a flat $objects array. We recursively resolve UIDs, unwrap NSDictionary / NSArray / NSData to recover the full SilicaBrush parameter dictionary (80+ keys across 14 Brush Studio panels).
04Texture Extraction & Inversionpending
Procreate: white = opaque. CSP: dark = opaque. We draw each texture to an offscreen canvas, apply per-pixel 255 - value inversion, then export as PNG for the .sut MaterialFile BLOB.

05Parameter Mappingpending
Maps ~80 Procreate keys to CSP equivalents: Direct (~60%), Approximate (~25%), No equivalent (~15%). Handles both old-style (pre-5.0: plotSpacing, dynamicsPressureSize) and new-style (5.0+: spacing, pressureSize) Procreate keys. Pressure curves use CSP linear default.

06SQLite .sut Constructionpending
A CSP .sut is a SQLite 3 database: Node (identity), Variant (all params as typed columns), MaterialFile (brush tip as TAR archive BLOB at thumbnail/thumbnail.png). Built with sql.js (SQLite → WebAssembly).
