How it’s converted

each step explains what it does
01Read Brushespending
A .brush is a ZIP. Its Brush.archive is an Apple binary plist (magic bplist00). A 32-byte trailer locates the offset table, and every object starts with a type nibble. The plist is an NSKeyedArchive: $top.root points by UID into a flat $objects table, and resolving those UIDs gives the SilicaBrush settings. A .brushset holds one folder per brush. The Reset/ copy some brushes carry is skipped.
02Shape & Grainpending
Procreate paints with white, and CSP with dark ink, so the shape is inverted. Brushes that use one of Procreate's built-in shapes only store its name, so common ones (hard, soft, oval) are approximated.
03Map Settingspending
Procreate keys map onto CSP Variant columns. The mapping is direct where the two apps mean the same thing and approximate where they don't quite. Brush sizes are estimates, since Procreate doesn't document its size unit. The table shows the first brush.
Procreate KeyValueCSP ColumnFidelity
04Write .sutpending
A CSP .sut is a SQLite 3 database with three tables. Node holds the name, Variant holds the settings as typed columns, and MaterialFile holds the tip as a tar archive containing thumbnail/thumbnail.png. It's built with sql.js (SQLite compiled to WebAssembly). Several brushes are downloaded together as a .zip.
